# Week 5 – Python Set and Duplicate Handling Projects 🐍

This repository contains my Week 5 Python practice projects as a first-year Artificial Intelligence and Machine Learning (AIML) student. These projects focus on sets, lists, set operations, user input, and handling duplicate values.

## 📂 Projects

### 1. Set Formation
Takes values as user input and creates a set from the given elements.

**Concepts Practised:**
- Sets
- User input
- Set creation
- Unique elements

### 2. Set Union
Takes two sets as user input and finds their union, combining all unique elements from both sets.

**Concepts Practised:**
- Sets
- Union operation
- User input
- Unique elements

### 3. Set Intersection
Takes two sets as user input and finds their intersection, identifying the elements that are common to both sets.

**Concepts Practised:**
- Sets
- Intersection operation
- User input
- Finding common elements

### 4. Removing Duplicate Values from a List
Takes a list as user input and removes duplicate values to create a list containing only unique elements.

**Concepts Practised:**
- Lists
- Sets
- Duplicate removal
- User input

### 5. Detecting Duplicate Values
Takes a list as user input and identifies which values appear more than once.

**Concepts Practised:**
- Lists
- Sets
- Loops
- Duplicate detection
- Comparing elements

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run a Python file using:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the actual name of the Python file you want to run.
